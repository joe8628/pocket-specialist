## Context
Surya OCR/layout and a missing-Transformers PP-DocLayout import path originally
called `sys.exit(1)` when their dependencies were unavailable. Inside a library,
phase code, test, or orchestrated worker, that kills the whole process.

## Decision
Rejected `sys.exit` on import/availability failure. Providers now raise
`RuntimeError` with install guidance and let the caller (CLI, test, worker)
decide how to present it. Library and phase code stay composable. Enforced by
RUL-0002.

## Alternatives considered
- Keep `sys.exit(1)` for a clean CLI message — rejected: convenient for one entry
  point, fatal for every other caller; the CLI can format a raised error itself.

## Consequences
Tests and orchestrated runs survive a missing provider and can assert on the
error. The CLI owns presentation of provider-unavailability messages.
