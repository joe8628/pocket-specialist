## Rule
Layout inference runs on a page rendered at a chosen zoom/DPI; native PDF text
coordinates come from PDF point space. Before matching native blocks against
layout regions, native coordinates must be scaled into the rendered-image
coordinate space using the same zoom/DPI used for layout inference. Matching uses
polygon-vs-bbox overlap scoring (preferred when polygons exist), falling back to
bbox intersection.

## Rationale
Mismatched coordinate spaces silently break region matching: native blocks land
in the wrong place and either fail to match or match the wrong region. This was a
real coordinate-space bug fixed by threading render zoom/DPI context into
`get_pdf_native_blocks()`. Overlap scoring replaced centroid-in-box matching,
which was too brittle for multi-column scientific layouts.

## Exceptions
none — any path that compares native blocks to layout regions must scale first.
