## Rule
A provider or model runtime that cannot import or initialize its dependencies
must raise `RuntimeError` with install/setup guidance. It must not call
`sys.exit`, `os._exit`, or otherwise terminate the host process. The caller
(CLI, test, or orchestrated worker) decides how to surface the error.

## Rationale
Provider code runs inside a library, phase code, tests, and orchestrated workers,
not only the CLI. A `sys.exit` convenient for one entry point is fatal for every
other caller. Produced by DEC-0014.

## Exceptions
none — the CLI may catch the raised error and exit at the top level, but the
provider layer itself never exits.
