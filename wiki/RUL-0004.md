## Rule
The presence of native text on a page does not mark the page complete. A native
text block satisfies only the layout regions it actually covers (by polygon/bbox
overlap). Any unmatched layout region — image-only formulas, figures, tables on
an otherwise digital page — must still be routed through the OCR/formula path and
merged back into the page result.

## Rationale
Treating native-text pages as fully complete let complex regions (e.g. image-only
formulas on digital pages) silently bypass OCR and UniMERNet, violating the spec
rule that complex regions can trigger OCR even when native text exists. Found in a
v0.5.1 §4–19 audit.

## Exceptions
When `layout.enabled = false`, region-guided routing is intentionally skipped:
digital pages use native text and pages without native text fall back to full-page
OCR (recorded as `layout_enabled: false`). See RUL-0005 for the coordinate rule
that makes overlap matching correct.
